An animated download button with progress, success and failure state transitions. Pure HTML, CSS & JavaScript microinteraction.

---

## ✨ Features

- ⬇️ Idle → Downloading → Success / Fail states
- 📊 Progress bar animation
- ✅ Success tick & ❌ Error shake
- ✨ Smooth CSS transitions
- ⚡ Zero dependencies
